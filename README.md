# SpendWise - Personal Expense Tracker

## Project Description
SpendWise is a simple web app to track daily expenses, add income, view balance, and manage spending. Users can add a transaction with description, amount and type (income/expense), see total income, total expense and balance, delete a transaction, and clear all. Data is saved in the browser with localStorage so it stays after refresh. It helps users see where their money goes and stay on budget.

## Technologies Used

- JavaScript for logic and localStorage

## Deployment Process Summary
1. Reviewed project structure and ensured index.html, style.css and script.js were in the main folder.
2. Created a public GitHub repository and pushed all project files.
3. Connected the GitHub repository to Netlify using GitHub integration.
4. Deployed the site from the main branch with no build command.
5. Changed the default Netlify subdomain to a custom meaningful name: spendwise-mindaye.
6. Tested the live site on mobile and desktop.

## Challenges Encountered During Deployment
- My files were empty at first and index.html was named wrong as index.htlm. I fixed the name and pasted the correct code.
- I had two CSS files, style.css and styles.css, which confused the styling. I deleted the duplicate and kept only style.css.
- Netlify gave a random site name. I learned how to change it in Site Settings.
- I had to wait for deployment to finish before the site showed updates.
